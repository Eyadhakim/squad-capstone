## Project Structure
- `index.html`, `styles.css`, `app.js` — baseline project scaffold
- `PROPOSAL.md` — squad proposal (roster, problem statement, MVP features, page map)
- `.github/pull_request_template.md` — template used for every Pull Request

## Git Workflow
- `main` is protected: no direct commits, and every change needs a Pull Request with at least 1 approving review.
- Each member works on their own branch named `feature/<short-description>` (for example `feature/proposal-<member-name>`).
- Every PR includes a 2-sentence Concept Comment explaining why an engineering decision was made.
- Every member reviews at least one teammate's PR before it is merged.
- Commits are atomic with descriptive messages.

## Run Locally
1. Clone the repo: `git clone https://github.com/<owner>/squad-<name>-capstone.git`
2. Open `index.html` in your browser.
